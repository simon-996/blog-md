## 什么是 HTML 元素？

HTML 标签包裹的内容统称为元素，是构成网页的基本单元。

根据显示方式和布局特性，元素主要分为两类：

- `块级`元素 (Block-level) 
- ` 行内`元素 (Inline-level)。

### 块级元素

在页面中`独占一行`，自动换行，默认宽度撑满父元素。

特性：

- **独占一行**：相邻块级元素上下排列，中间自动换行。
- **宽高可控**：支持设置 width、height、padding、margin。
- **可嵌套**：可以包含其他块级元素和行内元素。
- **常见场景**：页面布局、大区域划分、段落结构。

### 行内元素

在同一行内`依次排列`，不独占一行，宽度由内容决定。

特性：

- **同行显示**：相邻行内元素左右排列，空间不足时换行。
- **宽高不可控**：默认不支持设置 width、height，由内容决定。
- **仅容内容**：只能包含文本或其他行内元素，不可嵌套块级元素。
- **常见场景**：文字修饰、小图标、链接、短文本组合。

### 特殊元素：行内块元素

兼具行内和块级特性，同行显示且支持宽高。

特征：

- 同行排列（像行内元素）
- 可设置宽高、边距（像块级元素）

### display 属性：控制元素显示模式

HTML 元素的显示模式并非固定，可通过 CSS 的 display 属性灵活转换。

| 属性值       | 显示模式 | 特点                 | 应用场景           |
| ------------ | -------- | -------------------- | ------------------ |
| block        | 块级     | 独占一行、可设宽高   | 页面布局、大区域   |
| inline       | 行内     | 同行显示、不可设宽高 | 文字修饰、小元素   |
| inline-block | 行内块   | 同行显示、可设宽高   | 导航菜单、图标按钮 |
| none         | 隐藏     | 不显示、不占空间     | 动态隐藏元素       |

## **两个无语义标签**

`<div>` 和 `<span>` 是 HTML 中最常用、最纯粹的两个无语义容器标签。

无语义：本身不代表标题、段落、图片等含义
纯容器：专门用来包裹内容，方便划分结构 + 设置 CSS 样式

### `div`：块容器

- =快递盒 / 大箱子（块级）
- 自己独占一行
- 别人不能和它并排
- 可以装文字、图片、其他小盒子
- 用来划分页面大区域

### `span`：行内容器

- = 便利贴 / 小标签（行内）
- 不独占空间
- 和其他内容挤在同一行
- 只包裹一小段文字 / 小内容
- 用来局部修改样式

## CSS盒子模型

什么是盒子模型？
所有 HTML 元素都是一个 “方盒子”由 4 部分组成：

```
+---------------------------------------------------+
|                     margin                        |
|           (外边距，盒子与其他盒子的距离)            |
|   +-------------------------------------------+   |
|   |                 border                    |   |
|   |           (边框，盒子的边缘)               |   |
|   |   +-----------------------------------+   |   |
|   |   |             padding               |   |   |
|   |   |       (内边距，内容到边框)          |   |   |
|   |   |   +---------------------------+   |   |   |
|   |   |   |         content           |   |   |   |
|   |   |   |    (内容区，文字/图片)      |   |   |   |
|   |   |   +---------------------------+   |   |   |
|   |   |                                   |   |   |
|   |   +-----------------------------------+   |   |
|   |                                           |   |
|   +-------------------------------------------+   |
|                                                   |
+---------------------------------------------------+
```

- `content` 内容区：文字、图片所在区域
- `padding` 内边距：盒子内壁到内容的距离
- `border` 边框：盒子的边
- `margin` 外边距：盒子与其他盒子的距离

### padding 内边距（内壁留白）

控制内容与边框之间的距离，让文字不贴着边。

#### 四个属性对应四个方向

- `padding-top` 上内边距
- `padding-right` 右内边距
- `padding-bottom` 下内边距
- `padding-left` 左内边距

```css
/** 设置四个方向的内边距 **/
padding-top: 10px;

padding-right: 20px;

padding-bottom: 10px;

padding-left: 10px;
```

#### 简写写法（顺时针：上 右 下 左）

```css
/* 四个方向相同 */
padding: 10px;

/* 上下=10px 左右=20px */
padding: 10px 20px;

/* 上=10 右=20 下=30 左=40 */
padding: 10px 20px 30px 40px;
```

#### 特点

- 会撑大盒子（默认情况下，padding 会增加盒子的实际占用尺寸）
- 块级元素完全支持；行内元素左右 padding 正常生效，上下 padding 视觉生效但不占据空间（不影响其他元素布局）
- 背景色会覆盖 padding 区域

### margin 外边距（盒子间距）

控制盒子与盒子之间的距离。

#### 四个属性对应四个方向

- `margin-top` 上外边距
- `margin-right` 右外边距
- `margin-bottom` 下外边距
- `margin-left` 左外边距

```css
/** 设置四个方向的外边距 **/
margin-top: 10px;

margin-right: 20px;

margin-bottom: 10px;

margin-left: 10px;
```

#### 简写写法（和 padding 一样 上右下左）

```css
margin: 10px;          /* 四周 */
margin: 10px 20px;     /* 上下 左右 */
margin: 5px 10px 15px 20px; /* 上 右 下 左 */
```

#### 特点

- 不会撑大盒子
- 背景色不会覆盖 margin 区域
- 块级元素完全支持；行内元素左右 margin 正常生效，上下 margin 无效

#### margin: 0 auto 水平居中

块级元素设置了固定宽度后，可以用 `margin: 0 auto` 实现水平居中：

```css
.box {
    width: 300px;
    margin: 0 auto;  /* 上下为0，左右自动平分剩余空间 */
}
```

> 注意：必须设置了 width，`auto` 才能生效。如果没有宽度，元素默认撑满父元素，就没有剩余空间可以平分了。

#### margin 塌陷（合并）问题

在某些情况下，两个 margin 会"合并"成一个，取较大的值，而不是简单相加。

**1. 相邻兄弟元素的 margin 合并**

两个上下相邻的块级元素，上面的 `margin-bottom` 和下面的 `margin-top` 会合并，取较大的值：

```css
.box1 { margin-bottom: 30px; }
.box2 { margin-top: 20px; }
/* 实际间距 = max(30px, 20px) = 30px，而不是 50px */
```

**2. 父子元素的 margin 塌陷**

父元素没有设置 border、padding 或 overflow 时，子元素的 `margin-top` 会"穿透"到父元素外面：

```css
.parent { background: lightblue; }
.child { margin-top: 50px; }
/* 结果：parent 和 child 一起往下移了 50px，而不是 child 在 parent 内部往下 50px */
```

**解决办法：**

- 给父元素加 `border` 或 `padding`
- 给父元素设置 `overflow: hidden`
- 给父元素设置 `display: flow-root`

### 小练习：计算盒子尺寸

根据以下代码，计算盒子的实际占用宽度和高度：

```css
.box1 {
    width: 200px;
    height: 100px;
    padding: 20px;
    border: 5px solid black;
}
/* 实际宽度 = 200 + 20*2 + 5*2 = 250px */
/* 实际高度 = 100 + 20*2 + 5*2 = 150px */
```

## border边框

在 CSS 盒子模型中，**border（边框）** 是位于 `padding`（内边距）和 `margin`（外边距）之间的装饰性线条。它就像一个相框，围绕在元素内容和内边距的外围，用于定义元素的边界。

### border 的基本语法

简写属性

>border: border-width border-style border-color;
>
>border: 边框宽度 边框样式 边框颜色

示例代码

```css
/* 完整简写 */
border: 2px solid red;

/* 只设置样式 */
border: solid;

/* 设置宽度和样式 */
border: 3px dashed;
```

### border 子属性

#### border-color（边框颜色）

设置边框的颜色。

```css
border-color: red;
border-color: #ff0000;
border-color: rgb(255, 0, 0);
border-color: rgba(255, 0, 0, 0.5); /* 半透明 */
border-color: transparent; /* 透明边框 */
```

#### border-width（边框宽度）

设置边框的粗细程度。

```css
/* 具体数值 */
border-width: 1px;
border-width: 2pt;
border-width: 0.5em;

/* 关键字 */
border-width: thin;    /* 细边框 */
border-width: medium;  /* 中等边框（默认） */
border-width: thick;   /* 粗边框 */
```

#### border-style（边框样式）

设置边框的类型。

```css
border-style: none;      /* 无边框（默认） */
border-style: hidden;    /* 隐藏边框 */
border-style: dotted;    /* 点线 */
border-style: dashed;    /* 虚线 */
border-style: solid;     /* 实线 */
border-style: double;    /* 双线 */
border-style: groove;    /* 3D 凹槽效果 */
border-style: ridge;     /* 3D 垄状效果 */
border-style: inset;     /* 3D 内嵌效果 */
border-style: outset;    /* 3D 外凸效果 */
```

#### 方向性 border 属性

可以单独设置每个方向的边框：

```css
/* 单独设置每个方向 */
border-top: 2px solid blue;
border-right: 1px dashed red;
border-bottom: 3px double green;
border-left: 4px solid yellow;

/* 或者使用子属性 */
border-top-width: 2px;
border-top-style: solid;
border-top-color: blue;
```

#### border 简写规则

> 四值语法（顺时针：上 右 下 左）

```css
border-width: 1px 2px 3px 4px;
border-style: solid dashed dotted double;
border-color: red green blue yellow;
```

> 三值语法（上 左右 下）

``` css
border-width: 1px 2px 3px;
/* 等同于：上=1px, 右=2px, 下=3px, 左=2px */
```

> 二值语法（上下 左右）

```css
border-width: 1px 2px;
/* 等同于：上=1px, 右=2px, 下=1px, 左=2px */
```

>单值语法（四个方向相同）

```css
border-width: 1px;
/* 四个方向都是 1px */
```

### border-radius 圆角

让盒子的角变成圆角，常用于按钮、卡片、头像等场景。

#### 基本语法

```css
/* 四个角相同 */
border-radius: 10px;

/* 水平半径/垂直半径（椭圆角） */
border-radius: 20px / 10px;
```

#### 单独设置每个角

```css
border-top-left-radius: 10px;      /* 左上角 */
border-top-right-radius: 20px;     /* 右上角 */
border-bottom-right-radius: 30px;  /* 右下角 */
border-bottom-left-radius: 40px;   /* 左下角 */
```

#### 四值语法（顺时针：左上 右上 右下 左下）

```css
border-radius: 10px 20px 30px 40px;
/* 左上=10px 右上=20px 右下=30px 左下=40px */
```

#### 常见应用

```css
/* 圆角按钮 */
.btn {
    border-radius: 5px;
}

/* 胶囊按钮（高度的一半） */
.capsule {
    height: 40px;
    border-radius: 20px;
}

/* 正圆头像 */
.avatar {
    width: 100px;
    height: 100px;
    border-radius: 50%;
}

/* 椭圆头像 */
.ellipse-avatar {
    width: 120px;
    height: 100px;
    border-radius: 50%;
}
```

#### 注意事项

- `border-radius` 的值是圆角的**半径**
- 设为 `50%` 时，元素会变成正圆（正方形）或椭圆（矩形）
- 圆角效果需要元素有背景色或边框才能看到
